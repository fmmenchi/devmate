# devmate

A local developer-productivity assistant that takes an issue through agents — triage, plan,
implement, verify, review — to a draft pull request, and grades the work against your own rubric.
A human merges. Always.

- **[ADRs](./adr/index.md)** — every structural decision, and why.
- Each project's own documentation lives beside its code, in its `docs/` folder, and is
  assembled here at build time.

Agents working in this repository start from `AGENTS.md` at its root, not from this site.
